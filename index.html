GPT Agent 接口配置

前端不直接保存 API Key。真实上线时，页面调用你的后端接口，由后端负责调用 GPT、启用网页搜索/爬取能力、读取 URL 正文，并把结果返回给前端。Demo 默认开启演示模式，不会请求真实接口。

后端建议支持 action 字段：collect_urls、collect_dimension_urls、generate_dimension、generate_final。URL 采集建议返回严格 JSON；正文生成建议返回 content 字段。本页面已兼容 content、output_text、choices、urls 等常见返回格式。

Step 1：填写基础信息

用户只需要填这三个信息。示例：研究主体填“浦发银行”，银行所在地区填“上海”，研究时间填“2026”。

主流程不要求用户粘贴 URL。系统会自动找宏观、行业、区域、监管四个维度的高质量资料，并展示出来，方便用户检查来源是否靠谱。

Step 2：自动采集到的高质量 URL

这里是系统自动找出来的资料来源。每个维度都有一个“生成策略”选项，用户只需要选风格，不需要理解完整提示词；如果发现某条来源不合适，可以点“人工微调 URL”改一下，再重新生成对应维度。
